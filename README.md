# SYNTROXI: Future of Work

SYNTROXI Website Development Brief

This website is not a traditional agency website. It is a premium SaaS platform that sells AI Employees and Connected Business Systems. Every design decision should reinforce that SYNTROXI is building the future of work.

1. Project Setup

Start with a fresh production-ready project using:

 Next.js 15 (App Router)

 React 19

 TypeScript

 Tailwind CSS

 Framer Motion

 GSAP

 Lenis Smooth Scroll

 React Three Fiber + Three.js

 Shadcn/UI

 Lucide Icons

 Payload CMS

 Clerk Authentication

 Stripe + Razorpay

 Vercel deployment ready

Build with clean architecture, reusable components, SEO, responsiveness, accessibility and performance from the beginning.

2. Build the Entire Website

Do not only build the hero.

Build the complete website including every page, animation and interaction.

Pages

 Home

 AI Employees

 AI Employee Details (dynamic)

 Connected Systems

 AI Workforce Builder

 Industries

 Pricing

 Case Studies

 About

 Resources / Blog

 Contact

 Dashboard (client portal)

 Authentication

 Checkout

Every page should feel like it belongs to one premium design system.

3. Frontend First

For the first version:

 Design every page

 Implement all animations

 Build every interaction

 Create all UI components

 Make the navigation work

Backend integrations (Clerk, Stripe, Payload CMS and APIs) can use realistic mock data initially, but the architecture must be ready for production so they can be connected later without redesigning the UI.

4. Follow the SYNTROXI Design System

The website must match the new logo exactly.

Design language:

 White backgrounds

 Navy (#071A45)

 Electric Blue (#2F7DFF)

 Thin geometric lines

 Large whitespace

 Premium typography

 Rounded corners

 Soft shadows

 No glassmorphism

 No neon

 No cyberpunk

 No green

 No purple

 No dark mode as the primary experience

Everything should look clean, expensive and timeless.

5. Animation Philosophy

Animations should be subtle and premium.

Use:

 Fade

 Scale

 Blur

 Slide

 Stagger

 Parallax

 Cursor interactions

 Smooth scrolling

 Micro interactions

Avoid:

 Flashy effects

 Fast rotations

 Over-the-top particles

 Excessive glowing

 Constant motion

The website should feel alive, not distracting.

6. Most Important Sections

Prioritise these experiences:

 Animated Hero

 Interactive AI Employees Marketplace

 Connected Systems Visualisation

 AI Workforce Builder

 Workflow Animation

 ROI Calculator

 Pricing

 Dashboard Preview

 Case Studies

 Final CTA

These sections should be polished to a very high standard.

7. Component Architecture

Everything should be modular.

Examples:

 Navbar

 Footer

 Section wrapper

 Animated heading

 Feature cards

 Pricing cards

 AI Employee cards

 Workflow component

 Network background

 Timeline

 Buttons

 Forms

 Counters

 Charts

 Testimonials

No duplicated code.

8. Performance

Target:

 Lighthouse 95+

 Excellent Core Web Vitals

 Optimised images

 Lazy loading

 Code splitting

 Responsive across desktop, tablet and mobile

9. Overall Goal

When someone visits the site, they should immediately think:

"This is not another web agency. This is a world-class AI company building intelligent digital employees."

The experience should feel closer to Apple, Stripe, Linear, OpenAI and Vercel than to a typical SaaS template. 
also the logo is given to you
